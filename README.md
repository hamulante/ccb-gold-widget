# CCB Gold Widget

一个放在桌面角落的建行黄金积存看价小窗。

## 为什么做这个

因为买在高位了还能是为什么啊！！！

近期金价又跌了，手痒的散户本人想买一点平仓。手机上每次想看一眼金价，都得先登录，只是想知道涨了还是跌了，结果还得打开 App、登录、找入口。

但能忍住不看嘛，万一错过谷底呢༼ ༎ຶ ෴ ༎ຶ༽

于是搓个小窗在电脑边上，边上班边瞄一眼(￣▽￣)

## 能看什么

- 建行**主动积存**的买入参考价、赎回参考价，还有涨跌额和涨跌幅（为什么是建行，因为我买的是建行）。
- 自己的持仓数量、持仓均价和估算盈亏。数量、均价旁边的 `✎` 可以点，改完会记住。
- 默认每 5 秒取一次价。小窗可以拖到顺手的位置，也可以置顶。

第一次打开先放了 **20 克、均价 900 元/克** 的示例，记得点铅笔改成自己的持仓。已经保存过的持仓不会被这些默认值覆盖。
- 数据来自[建行官网的主动积存行情](https://www.ccb.com/chn/home/gold_new/hqzs/index.shtml)。这里不登录银行账户，也不负责交易，就是个看价的小工具。持仓是手动填的，只保存在自己电脑上。

## 怎么用

Windows 下，双击 `GoldWidget.exe` 就能打开。用的是 Windows 的 .NET Framework。

仓库里放的是源码。如果还没有 exe，按下面“想自己改”里的方法编译一次就有了。

- 按住数字或空白处拖动，点“置顶”切换是否保持在其他窗口前面。
- `↻` 手动刷新，`×` 退出；右键可以把刷新间隔改成 5、10 或 30 秒。
- 鼠标停在价格或状态上，可以看完整报价时间和详细信息。
- 改好的持仓会存在 `%LOCALAPPDATA%\GoldWidget\holdings.json`，重启后还在。

可以给程序建个快捷方式，放进 `Win + R` → `shell:programs` 打开的文件夹。想开机自动运行，就放进 `shell:startup`。程序本身不会默认开机自启。如果移动了项目文件夹，记得把快捷方式的目标路径也改一下。

## 盈亏怎么算

```text
持仓盈亏 =（建行参考赎回价 − 持仓均价）× 持仓数量
```

用的是**赎回价**，不是买入价。金额显示到分，盈利红色、亏损绿色。上面的行情涨跌是相对建行上次收盘买入价算的，另外收取的手续费没有算进去。

官网参考报价和 App 当时能成交的价格也可能不同，真要买卖还是以建行确认页为准。

## 价格怎么灰了

先看底下的报价时间。接口延迟、休市或者请求失败，都可能让价格停在原地。

超过两分钟没新报价，数字就会变灰并标成“旧报价”；请求失败也会提示，之后自动重试。没有拿到价格时就显示 `--.--`，不会随便找个别的金价凑上去。

每 5 秒取一次数据，这个工具用的是官网公开图表接口，不是有稳定性保证的开放 API，哪天建行改接口了，也可能需要跟着修。

## 想自己改

C# + Windows Forms，直接用 Windows 的 .NET Framework 编译器，不需要另外装一套开发工具。

先关闭正在运行的小窗，再在项目目录里打开 PowerShell：

```powershell
.\build.ps1
```

编译好的 `GoldWidget.exe` 就在当前目录。想顺手跑测试，用 `.\build.ps1 -Test`；想连建行的真实接口一起测，用 `.\build.ps1 -LiveTest`。

如果 PowerShell 拦住了脚本，可以这样跑，只对这一次进程生效：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```
